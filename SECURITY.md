# Security

Report vulnerabilities privately through GitHub Security Advisories for
`cloud-itonami/cloud-itonami-numbering`.

Do not include Telnyx API keys, operator tokens, Passkey assertions, telephone
numbers belonging to real people, or regulatory documents in an issue.

The service listens on loopback only. A production deployment must add its own
authenticated transport boundary; loopback is reach restriction, not identity.
